ВИТЁК: ПУТЬ К ДЕВЯТКЕ
Стартовый проект Godot 4.3+.

СОДЕРЖИМОЕ
- scenes/main.tscn: главная сцена
- scripts/world.gd: двор, игрок, камера, сбор бутылок, HUD и подработка
- android/BUILD_NOTES.txt: заметки по Android-сборке

УПРАВЛЕНИЕ
WASD или стрелки — ходить; E или кнопка «Подработка» — получить 25 ₽ один раз за запуск; сбор зелёных бутылок — +5 ₽.

СБОРКА
Android APK собирается GitHub Actions при push в main. APK публикуется как workflow artifact. Это прототип: геометрия двора пока состоит из примитивов, 3D-модели и дополнительные игровые системы ещё предстоит добавить.
